Architecture de Pointe

Construit pour l'efficacité absolue et conçu sur-mesure pour les GPUs NVIDIA Ampere et Ada Lovelace.

⚡

Double-Buffering Asynchrone

Le pipeline E2E masque 100% de la latence PCIe. Pendant que le GPU calcule le batch N, le CPU rapatrie les résultats du batch N-1 en mémoire verrouillée (Pinned Host Memory).

🧠

L2 Cache Pinning

Politique L2 persistante (cudaAccessPropertyPersisting) activée sur les architectures compatibles pour conserver les matrices A et B au plus près des cœurs de calcul, évitant les allers-retours VRAM coûteux.

🎯

Tiled-32x8 Candidate Order

Le parcours mémoire des noyaux v12d et v8c a été redessiné pour une localité registre maximale, optimisant le warp-level caching et réduisant la pression mémoire.

Démarrage Rapide

  1. Téléchargez l'archive `.zip` depuis la page GitHub Releases.
  2. Extrayez l'intégralité des fichiers dans un dossier sur votre bureau.
  3. Modifiez le fichier start.bat (clic droit -> Modifier) pour y insérer l'adresse de votre Wallet Pearl.
  4. Exécutez start.bat (Recommandé: Lancer en tant qu'Administrateur pour permettre l'optimisation des horloges si configuré). 
@echo off
:: Pinctada Miner v1.3.0 - Lanceur
set POOL=stratum+tcp://prl.kryptex.network:7048
set WALLET=VOTRE_WALLET_ICI
set WORKER=MonRig01

pinctadaminer.exe --url %POOL% --wallet %WALLET% --worker %WORKER%
pause
